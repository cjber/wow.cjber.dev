WoW: Forever Profile

Forever profile

Your character's card

The Forever addons can turn one character's own progress into a single link: quests, journeys and distance, recipes, flight paths, commissions and the creatures you have met. Sharing the link shares the card.

  1. In game, type /forever profile.
  2. The window shows a link, already selected. Press Ctrl+C (Cmd+C on a Mac).
  3. Open the link here to see the card, or send it to a friend.

The code is in the part of the link after the #, so it never reaches this site's server. Nothing is uploaded, stored or tracked, and there are no accounts.
